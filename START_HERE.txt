DEAD CELLS MOD LAUNCHER - CLEAN GITHUB UPLOAD

1. Create a new PUBLIC GitHub repository named DeadCellsModLauncher.
2. Extract this ZIP on your PC.
3. Open the extracted folder.
4. Upload EVERYTHING INSIDE the folder to the root of the new GitHub repository.
   Do not upload the ZIP itself and do not upload the outer extracted folder as another folder.
5. Commit the upload.
6. Go to Settings -> Pages.
7. Choose Deploy from a branch.
8. Branch: main
9. Folder: /docs
10. Save.

.github/
assets/
docs/
src/
.gitignore
